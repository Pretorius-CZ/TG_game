Qui exploite le jeu

Le responsable du traitement est Michal Malich. Pour toute question ou demande concernant vos données personnelles, écrivez à flambiz.cz@gmail.com.

Sauvegardes locales et stockage du navigateur

Le jeu stocke dans le navigateur les copies de progression invitées et de compte, étoiles, récits lus, réglages, énergie, outils et données de session. Les deux adresses ont des stockages distincts. Effacer les données du navigateur peut supprimer les sauvegardes locales ; se déconnecter ne supprime pas le compte. Les pages d’information mémorisent votre langue et ne lancent ni statistiques de jeu ni connexion Google.

Connexion Google facultative et progression cloud

La connexion Google passe par Supabase. Si vous vous connectez, Supabase traite l’identifiant de compte, l’adresse e-mail et les informations de profil fournies par Google, ainsi que votre session. Progression, évaluations et entrées lues sont liées à ce compte pour continuer sur un autre appareil. Énergie et outils restent locaux, sans inventaire cloud partagé. Les données de connexion sont nécessaires à ces fonctions ; le jeu sans compte reste possible.

Statistiques de jeu

Uniquement si vous choisissez « Autoriser les statistiques » au premier lancement ou dans Paramètres du jeu, nous envoyons à Supabase, sous un identifiant de navigateur aléatoire, les données de jeu et de visite : niveaux, résultats, tentatives, coups, durée, objectifs, aides, horaires, catégorie d’appareil et paramètres de campagne de l’URL. Ces données sont pseudonymes, sans garantie d’anonymat. Le rapport de jeu n’ajoute pas intentionnellement votre nom Google ou votre e-mail.

Avec les statistiques activées, le jeu demande un code pays à country.is. Ce service reçoit votre adresse IP pour déterminer le pays. Seul le code pays rejoint nos statistiques. Les hébergeurs et prestataires peuvent aussi traiter les adresses IP et journaux de requêtes pour fournir le service.

Publicités et consentement

Le jeu utilise actuellement des publicités de test clairement signalées. Elles ne montrent pas de publicité payante et les vues simulées ne génèrent aucun revenu publicitaire. Une balise de vérification AdSense et un fichier ads.txt sont présents ; ils ne chargent pas de publicités à eux seuls.

Avant d’activer de vraies publicités Google, nous configurerons le message de consentement applicable et actualiserons ces informations pour l’intégration utilisée. Google et ses partenaires pourront alors utiliser cookies, stockage du navigateur, adresses IP et identifiants similaires pour diffuser, mesurer et, lorsque permis, personnaliser les annonces. Les choix seront accessibles dans le message et ses réglages de confidentialité. Utilisez les choix publicitaires dans Paramètres du jeu ou le pied de page pour rouvrir le message Google. Celui-ci doit être publié et disponible pour ce site. L’absence de données de consentement ne vaut jamais acceptation. Sans les autorisations nécessaires, nous ne lançons pas de publicité récompensée ; le jeu normal reste accessible.

Consultez comment Google utilise les informations des sites partenaires et les informations publicitaires de Google.

Un lien de test facultatif destiné au développement peut charger le SDK Google H5 après une demande de récompense. Il utilise le mode test et affiche une annonce fictive, pas un placement rémunéré. Charger le SDK contacte les serveurs Google. Les visites ordinaires continuent d’utiliser notre simulateur local.

Test de jeu à l’aveugle facultatif

Le lien distinct playtest.html propose un choix explicite sur les données de test avant de jouer. Il conserve séparément l’ordre, les configurations et les résultats, puis envoie tentatives, coups, durée, aides, utilisation des charges, évaluations de difficulté et notes facultatives sous une identité aléatoire distincte. Il n’utilise ni connexion Google, ni sauvegardes ordinaires, ni choix statistiques ordinaires et ne demande ni pays ni publicités. L’envoi peut être suspendu ; les résultats locaux restent exportables. Reprenez sur le même navigateur et appareil. La conservation serveur est aussi de 90 jours. Les données locales restent jusqu’à l’effacement du navigateur. Pour les supprimer, contactez le responsable en donnant seulement l’identifiant de session du fichier exporté, jamais des jetons privés.

Application Android et paramètres d’âge

L’application de test Android demande une tranche d’âge avant d’activer les fonctions en ligne. Seul le groupe choisi est enregistré sur l’appareil, pas la date de naissance. Les moins de 18 ans et les personnes qui ne souhaitent pas indiquer leur âge jouent localement, sans connexion Google, demande publicitaire ni transmission de statistiques de jeu. Leur progression reste sur l’appareil. Les adultes peuvent choisir séparément les sauvegardes Google dans le cloud et les statistiques facultatives. Les publicités récompensées pour adultes utilisent actuellement des annonces de démonstration Google ; Google Mobile Ads et UMP traitent les demandes et les choix de consentement lors de leur utilisation. Le choix d’âge ne remplace pas le consentement publicitaire.

Prestataires et finalités

GitHub Pages héberge le site ; Supabase fournit authentification, sauvegardes cloud et rapports ; Google propose la connexion facultative ; country.is détermine le pays. Les e-mails sont traités via Gmail. Les données du compte servent à fournir la connexion et la sauvegarde demandées. Les statistiques facultatives reposent sur votre consentement pour améliorer la difficulté et comprendre les visites. Vous pouvez refuser ou retirer ce choix dans Paramètres du jeu sans perdre le jeu, les récompenses ou le cloud. Le consentement publicitaire est distinct. Nous ne vendons ni sauvegardes ni coordonnées. Les prestataires peuvent traiter des données hors de votre pays ; consultez GitHub, Supabase et Google pour leurs informations de confidentialité.

Conservation et suppression

Les sauvegardes locales restent jusqu’à leur effacement, remplacement ou réinitialisation. L’historique local facultatif est limité à 2 000 tentatives ; les données de plus de 90 jours sont supprimées à la prochaine ouverture. Désactiver les statistiques efface l’historique local et les files d’envoi ; les réactiver n’envoie jamais l’historique antérieur au consentement. Les sauvegardes cloud restent avec le compte jusqu’à réinitialisation ou suppression après demande vérifiée. Réinitialiser la progression ne supprime pas le compte. Les données détaillées de jeu et de visite expirent après 90 jours lors du nettoyage quotidien, soit au plus un jour supplémentaire. Les identités de rapport inactives sont également supprimées après 90 jours quand aucun enregistrement conservé n’en dépend. « Désactiver et supprimer mes statistiques » dans Paramètres du jeu demande la suppression des données serveur de ce navigateur. Les demandes hors ligne ou échouées restent en attente et peuvent être relancées. Cela ne supprime ni progression ni compte. Chaque autre navigateur ou adresse possède une identité à traiter séparément. Un identifiant révoqué minimal et un secret haché sont conservés uniquement pour empêcher d’anciens clients de recréer les statistiques effacées ; ils sont exclus du nombre de joueurs. Journaux de service et sauvegardes techniques suivent les règles des prestataires. Contactez le responsable pour accès, suppression ou opposition ; des précisions peuvent être nécessaires pour retrouver vos données. N’envoyez pas de jetons de session.

Vos choix et vos droits

Vous pouvez jouer sans compte, vous déconnecter, gérer le stockage et demander, selon le cas, accès, rectification, suppression, limitation ou portabilité de vos données. Vous pouvez vous opposer au traitement et retirer un consentement sans affecter les traitements antérieurs. Contactez l’adresse ci-dessus. Vous pouvez aussi saisir votre autorité de contrôle, dont l’Office tchèque de protection des données personnelles.
